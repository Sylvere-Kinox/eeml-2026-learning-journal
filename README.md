# EEML 2026 — Notes de cours

Notes personnelles rédigées lors de l'Eastern European Machine Learning Summer School (EEML 2026), qui s'est tenue du 27 juillet au 1er août 2026 à Cetinje (Monténégro), suivie à distance.

Ce dépôt met à disposition ces notes sous un format structuré par journée et par thème, avec les documents PDF associés.

## Organisation du dépôt

Le contenu est découpé par journée de formation. Chaque dossier contient un résumé des notions abordées, le PDF correspondant et le fichier source Word.
